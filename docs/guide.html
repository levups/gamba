Guide

Gamba answers to Prawn’s API: installing it is swapping gems. This page covers what it brings on top, and its own API, which existing code adopts one block at a time.

Installation

# Gemfile
gem "gamba" # instead of prawn, prawn-table and prawn-svg

Gamba needs Ruby 3.3 or later. It depends on addressable, css_parser, matrix and rexml, which only its SVG support loads.

Remove prawn, prawn-table and prawn-svg from the Gemfile: Gamba refuses to load next to the prawn gem, with a LoadError saying so, rather than mixing two engines in one process.

Drop-in usage

Code written for Prawn runs as it is. Gamba provides require "prawn", require "prawn/table", require "prawn-svg" and require "prawn/measurement_extensions", and the Prawn namespace: Prawn::Document, Prawn::Table, Prawn::Errors, Prawn::SVG.

require "prawn"

Prawn::Document.generate("invoice.pdf", page_size: "A4", info: {Title: "Invoice"}) do
  font "DejaVuSans.ttf"
  text "Invoice INV-2026-0001", size: 14, style: :bold
  table [%w[SKU Qty Price], %w[A-1 2 $10.00]], header: true
  number_pages "<page>/<total>", at: [bounds.right - 50, 0], width: 50, align: :right
end

Prawn::VERSION answers "2.5.0", the version of the API Gamba mirrors, because Prawn extensions check it. Gamba’s own version is Gamba::VERSION.

The contract is Prawn 2.5’s public methods, listed in test/contract/prawn-2.5.0.yml: Gamba accepts every call Prawn accepts on those, and test/contract/decisions.yml records, method by method, what is in and why the rest is left out.

Gamba’s own API

Gamba.document writes a document without Prawn’s conventions. The block receives the document instead of running inside it, so your own methods and instance variables stay in reach. Options are keywords, and a mistyped one raises an ArgumentError that lists the accepted ones, where Prawn ignores it.

require "gamba"

document = Gamba.document(page_size: "A4", margin: 36, lang: "en") do |document|
  document.register_font "Inter", normal: "Inter.ttf", bold: "Inter-Bold.ttf"
  document.style :default, font: "Inter", size: 10
  document.style :title, size: 18, weight: :bold

  document.text "Invoice INV-2026-0001", style: :title
  document.text "Due on 1 December 2026", color: "666666"
  document.draw InvoiceLines.new(invoice)
end
document.write("invoice.pdf") # or an IO; document.to_s gives the bytes

A style names text attributes (font, size, weight, italic, color, align, leading); the :default style applies to every text, and what a call passes wins over its style. draw takes any object that answers call(document), so a document is made of small classes you can test one by one. Fonts registered here use their ligatures and kerning: there is no Prawn page to match. Pass features: [] to register_font to turn them off.

Layout is described, not computed. A stack puts its children one under the other, a row side by side; each box is measured before anything is drawn, so a row is as high as its tallest child and what follows starts below it, without a bounding_box, a float or a move_down.

document.row(gap: 24, padding: 12, background: "f5f5f5", border_color: "cccccc") do |row|
  row.stack(gap: 4) do |stack|
    stack.text "Alice Martin", style: :title
    stack.text "1 Example Street, 75001 Paris"
  end
  row.text "Due on 1 December 2026", width: 150, align: :right
end

document.stack(gap: 8) do |stack|
  paragraphs.each { |paragraph| stack.text paragraph }
  stack.stack(keep_together: true, padding: [6, 10], border_width: 1) do |total|
    total.text "Total", weight: :bold
    total.text "1 234,00 €"
  end
end

In a row, a child given a width takes it and the others share what is left, in proportion to their grow (1 unless told). Both containers take gap, padding (one number, [vertical, horizontal] or [top, right, bottom, left]), background, border_width and border_color.

A stack breaks pages between its children, and a text between its lines. A row, a stack with keep_together: true and a stack with a background or a border move whole to the next page when the rest of this one is too short; one that is higher than a page raises Prawn::Errors::CannotFit, saying which box and by how much.

Pages break where a reader expects them. A paragraph never leaves fewer than orphans lines at the bottom of a page, nor fewer than widows at the top of the next: 2 each unless told, 1 to break anywhere. A paragraph too short to keep both moves whole to the next page; one that starts a page fills it whatever its rules.

A box with keep_with_next: true goes to the next page together with the start of the box after it: the first lines of a paragraph, the header and first row of a table, all of a box that cannot be split. Headings are the usual case, so the three can sit in a style:

document.style :heading, size: 16, weight: :bold, keep_with_next: true
document.style :body, widows: 3, orphans: 3

document.text "Payment terms", style: :heading
document.text terms, style: :body
document.text "Lines", style: :heading
document.table(lines, columns: columns)

This works in stacks and on the document, where a kept box waits for the next one to be placed with it; anything drawn through document.prawn, or the end of a gamba block, places it first. Boxes kept together that would not fit on one page break as if they were not kept.

Tables and images are boxes too, on the document, in a stack or in a row. A table has named columns: its rows are hashes, or objects answering the columns’ names, so nothing is counted by position. Each column takes a title (its name, spelled out, unless told), a width, an align and the text attributes weight, italic, size and color. Without columns, a table of hashes has those of its first row.

lines = [{sku: "A-1", description: "Gadget", quantity: 2, total: "20,00"}]

document.table(lines,
  columns: {
    sku: {title: "SKU", width: 60},
    description: {},
    quantity: {title: "Qty", align: :right},
    total: {align: :right, weight: :bold}
  },
  header: {background: "333333", color: "ffffff"},
  stripes: %w[ffffff f6f6f6],
  cell: {size: 9, padding: 4, border_color: "cccccc"})

A table takes the width of its box, unless every column has its own, and in a stack it runs over pages with its header repeated. The header row is made of the titles, in bold; header: takes its style (align, weight, italic, size, color, background) or false to leave it out. stripes alternates row backgrounds, and cell styles every cell: padding, size, font, color, background, borders, border_width, border_color. For what these do not cover, such as a span or the style of one cell, the block receives the Prawn::Table before it is laid out; Prawn’s table of arrays itself stays at document.prawn.table.

document.table(lines, columns: columns) do |table|
  table.row(-1).borders = [:top]
  table.cells[3, 2].background_color = "ffeeee"
end

An image keeps its own size unless told a width or a height, is never wider than its box, and keeps its proportions; align puts it on the left, the centre or the right of its box. The same file placed twice is embedded once. SVG is not a box yet: draw it through document.prawn.

A header and a footer are declared once, before the body. Each block receives a stack to fill and the page, which answers number and total; it is run for every page when the document is rendered, once the pages are counted, in place of Prawn’s repeat and number_pages.

document.header(gap: 16) do |header, page|
  header.row do |row|
    row.text "Example SAS", weight: :bold
    row.text "Invoice INV-2026-0001", align: :right
  end
end

document.footer(gap: 12) do |footer, page|
  footer.text "Page #{page.number} of #{page.total}", align: :center, size: 8
end

Their room is taken from the page: the body, native or drawn with Prawn’s own calls, starts below the header and its gap and breaks pages above the footer and its gap. The room kept is the height each has on the page it is declared on, and it applies from that page on, so a cover page declared before them has neither. A header that comes out higher on a later page raises Prawn::Errors::CannotFit when the document is rendered, naming the page, instead of running over the body.

You don’t have to rewrite anything to start. In code written for Prawn, gamba opens a native block at the cursor, and leaves the cursor below what it drew:

Prawn::Document.generate("report.pdf") do
  text "Existing code, unchanged"
  gamba { |document| document.text "A first native block", size: 18, weight: :bold }
  text "More existing code"
end

The other way round, document.prawn is the Prawn::Document underneath, with all of Prawn’s API: tables, images, SVG and graphics go through it until the native API covers them. This API is guarded like Prawn’s: test/contract/gamba.yml lists every public method with its signature.

Tables

The API of prawn-table 0.2.2, built in: table, make_table, cell, make_cell, with their cell styles, headers repeated across pages, column widths, row and column spans, and subtables. No other gem and no require are needed.

table [%w[SKU Description Qty], *lines], header: true, width: bounds.width, cell_style: {padding: 3} do
  row(0).font_style = :bold
  column(2).align = :right
end

SVG

The API of prawn-svg 0.40.4, built in: svg data, options loads SVG support on first use.

svg File.read("logo.svg"), width: 120, position: :right
OptionWhat it does
at, position, vpositionWhere the image goes, as in Prawn’s image
width, heightIts size; the other dimension follows the aspect ratio
enable_web_requestsLets the SVG fetch images from http and https URLs. Off by default, where prawn-svg 0.40 has it on: see Compatibility
enable_file_requests_with_rootLets the SVG read local files under this directory
cache_imagesKeeps fetched images between calls
fallback_font_nameThe font used when the SVG names one the document does not know
color_mode:rgb or :cmyk
languageThe language <switch> elements match against
log_warningsPrints the warnings collected while reading the SVG

Fonts

Prawn’s fonts, unchanged in use: the 14 standard PDF fonts, TrueType files (.ttf), collections (.ttc) and .dfont, font_families.update, and fallback_fonts. OpenType fonts with CFF outlines (.otf) embed like TrueType ones, and render like the font itself.

A parsed font is shared by every document of the process, and every thread, until its file changes: a server reads Inter.ttf once, not once per PDF.

OpenType features

Ligatures and GPOS pair kerning move glyphs away from where Prawn puts them, so they stay off unless asked for, per font:

font "Inter.ttf", features: %i[liga kern]
font_families.update("Inter" => {normal: {file: "Inter.ttf", features: %i[liga kern]}})

liga applies the font’s standard ligatures (GSUB); kern applies its GPOS pair kerning.

Images

JPEG images are embedded as they are; PNG images in every variant Prawn reads, alpha included, are decoded. The same image placed twice in a document is embedded once.

A corrupt or hostile file raises Prawn::Errors::UnsupportedImageType or a named font error, never a crash inside a parser: PNG data inflates no further than its header announces. An input fuzzer checks it on flipped bytes, truncations and forged lengths.

PDF/A and Factur-X

Prawn::Document.new(pdf_a: true, info: {Title: "Invoice INV-2026-0001"}) do
  font "Inter.ttf"
  # …
  factur_x File.read("factur-x.xml"), profile: :en16931
end

pdf_a: true writes a PDF/A-3b document (ISO 19005-3): XMP metadata matching the info hash, an sRGB output intent, a file identifier, and annotations flagged for printing. What PDF/A forbids raises Prawn::Errors::PdfAViolation: a standard PDF font, which cannot be embedded, and encryption.

factur_x(xml, profile:, filename:, description:) embeds the CII XML of a Factur-X invoice into a PDF/A-3 document, with the relationship the specification gives each profile. Gamba does not build that XML: it embeds the one the invoicing system produced.

ArgumentValues
profile:minimum, :basic_wl, :basic, :en16931 (default), :extended
filename"factur-x.xml" by default
description"Factur-X invoice" by default

The test suite checks PDF/A documents with veraPDF when it is installed (brew install verapdf).

Output

Whatever does not move a pixel is on by default. Every document is written as PDF 1.5: streams compressed, every other object packed into one compressed object stream, and a compressed cross-reference stream instead of the xref table (ISO 32000-1 §7.5.7, §7.5.8).

Servers that fork

TrueType and SVG support load on first use, so a document of standard fonts never pays for them. Before a server forks its workers, load them once, so every worker shares that memory instead of loading its own copy:

# config/puma.rb, before_fork, or an initializer
Gamba.eager_load!

Comparing an app’s PDFs

script/capture_pdfs.rb writes every PDF an app’s test suite renders, named after its test. Run the suite under Prawn, then under Gamba, and compare both directories with Oracle.pdf_differences:

GAMBA_CAPTURE_DIRECTORY=tmp/prawn RUBYOPT=-r/path/to/gamba/script/capture_pdfs.rb bin/rails test
